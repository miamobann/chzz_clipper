# 치지직용 간단 클리퍼(비공식)

치지직 방송을 단축키로 움짤(WebP)·영상(MP4)으로 저장하는 크롬 확장 프로그램입니다.

> 개인 감상용 비공식 도구입니다. 저장한 클립의 저작권은 스트리머에게 있으며, 공유·재업로드 시 반드시 스트리머의 허락을 받아야 합니다. 사용에 따른 책임은 사용자에게 있습니다.

## 설치 (3단계)

1. 이 페이지의 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다. (Releases에 zip이 있으면 그것을 받아도 됩니다) 풀린 폴더는 지우거나 옮기지 않습니다.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 풀린 폴더 선택
3. 열려 있던 치지직 탭을 새로고침합니다.

**업데이트**: 새로 내려받은 파일로 폴더를 덮어쓴 뒤 `chrome://extensions`에서 이 확장의 새로고침(↻), 치지직 탭 새로고침.

## 시작하기

1. 치지직 방송에서 확장 아이콘을 눌러 그 채널의 **움짤**·**영상** 스위치를 켭니다. (채널마다 따로, 처음 보는 채널은 꺼짐)
2. 몇 초 재생한 뒤 단축키를 누르면 바로 저장됩니다.
3. 세부 설정은 팝업의 **⚙ 설정**에서 바꿉니다.

## 단축키

| 단축키 | 기능 |
|---|---|
| **Alt+Shift+S** | 움짤 저장 (최근 3~15초) |
| **Alt+Shift+V** | 영상 저장 (최근 5~60초, 소리 포함) |
| **Alt+Shift+D** | 영상이 켜진 모든 탭 동시 저장 |
| **Alt+Shift+E** | 교차편집 (영상이 켜진 탭 최대 5개) |
| (직접 지정) | 다듬어 저장 — 최근 장면의 시작·끝을 정해 저장 |
| (직접 지정) | 녹화 시작/종료 — 누른 시점 10초 전부터, 종료하면 다듬기 화면 (최대 10분) |

단축키 확인·변경: `chrome://extensions/shortcuts`. 다른 프로그램과 겹치면 비어 있을 수 있습니다.

## 저장 위치와 파일 이름

- 기본: `다운로드/치지직움짤클립/스트리머명/방송제목｜날짜/`
- 설정에서 다른 폴더(다운로드 밖 포함)나 채널별 폴더를 고를 수 있습니다.
- 파일 이름: `[스트리머명｜방송제목] yy-mm-dd hh：mm：ss.mp4`

## 다듬어 저장 · 교차편집

- 초록 표시를 끌거나 `I` / `O`로 시작·끝 지정, `Space` 재생, `Ctrl+Z` 되돌리기
- 교차편집: `1`~`5` 또는 화면 클릭으로 그 순간부터 해당 방송으로 전환, **소리로 자동 맞추기**로 싱크 조절
- 화면 자르기: 자유 / 16:9 / 9:16 / 1:1 / 4:3
- 저장 창에서 MP4 또는 움짤을 고르고 예상 용량을 확인할 수 있습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 아이콘에 빨간 `!` | 치지직 탭을 새로고침 |
| 단축키가 안 됨 | `chrome://extensions/shortcuts`에서 키 지정 |
| "이 채널은 ○○이 꺼져 있습니다" | 팝업에서 그 채널 스위치 켜기 |
| 화질이 가끔 크게 떨어짐 | 치지직 플레이어 화질을 "자동" 대신 1080p로 고정 |
| 움직임이 많은 장면이 뭉개짐 | 설정 → 영상 압축 품질 "최고" |
| 방송이 버벅임 | 켠 채널 수 줄이기, 화질·fps 낮추기 |
| 소리가 빠름/느림 | 설정 → 소리 싱크 보정 (빠르면 +, 느리면 −) |
| 그 밖의 문제 | 팝업 상태 줄의 내용을 함께 알려 주세요 |

## 이용 안내 및 면책

* 이 확장프로그램은 개인적인 감상·소장 목적으로 만든 비공식 도구이며, 네이버 및 치지직과 관련이 없습니다.
* 저장되는 영상·이미지의 저작권은 해당 스트리머와 원저작자에게 있습니다.
* 저장한 파일을 SNS·커뮤니티·영상 플랫폼 등에 올리거나 공유하려면 반드시 해당 스트리머의 허락을 받아야 합니다. 스트리머가 정한 2차 창작·클립 규정을 따라야 합니다.
* 영리 목적 사용, 무단 재배포, 편집 후 재업로드 등은 저작권법 위반이 될 수 있습니다.
* 이 도구를 사용해 생긴 저작권 침해 및 분쟁의 책임은 사용자 본인에게 있으며, 제작자는 책임지지 않습니다.
* 치지직 이용약관을 지켜서 사용하시기 바랍니다.

## 개인정보

- 권한은 `storage`, `downloads`, `offscreen`만 사용하며, 페이지 접근은 `chzzk.naver.com`으로 한정됩니다.
- 외부로 보내는 정보는 스트리머 이름·방송 제목 조회(치지직 API, 채널 ID·영상 번호)뿐이며, 수집·공유 기능은 없습니다.
