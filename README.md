# 치지직용 간단 클리퍼(비공식)

> 개인 감상용 비공식 도구입니다. 저장한 클립의 저작권은 스트리머에게 있으며, 공유·재업로드 시 반드시 스트리머의 허락을 받아야 합니다. 사용에 따른 책임은 사용자에게 있습니다.

## 이용 안내 및 면책

* 이 확장프로그램은 개인적인 감상·소장 목적으로 만든 비공식 도구이며, 네이버 및 치지직과 관련이 없습니다.
* 저장되는 영상·이미지의 저작권은 해당 스트리머와 원저작자에게 있습니다.
* 저장한 파일을 SNS·커뮤니티·영상 플랫폼 등에 올리거나 공유하려면 반드시 해당 스트리머의 허락을 받아야 합니다. 스트리머가 정한 2차 창작·클립 규정을 따라야 합니다.
* 영리 목적 사용, 무단 재배포, 편집 후 재업로드 등은 저작권법 위반이 될 수 있습니다.
* 이 도구를 사용해 생긴 저작권 침해 및 분쟁의 책임은 사용자 본인에게 있으며, 제작자는 책임지지 않습니다.
* 치지직 이용약관을 지켜서 사용하시기 바랍니다.

## 기능

| 단축키 | 기능 | 대상 | 길이 | 소리 |
|---|---|---|---|---|
| **Alt+Shift+S** | 움짤(WebP) 저장 | 현재 탭 | 3~15초 | 없음 |
| **Alt+Shift+V** | 영상(MP4) 저장 | 현재 탭 | 5~60초 | 있음 |
| **Alt+Shift+D** | 영상 동시 저장 | 영상이 켜진 모든 탭 | 5~60초 | 있음 |
| **Alt+Shift+E** | 교차편집 | 영상이 켜진 탭 최대 5개 | 최근 60초 | 있음 |
| (직접 지정) | 다듬어 저장 | 현재 탭 | 원하는 구간 | MP4만 |
| (직접 지정) | 녹화 시작/종료 | 현재 탭 | 누른 시점 10초 전 ~ 종료 (최대 10분) | 있음 |

- 파일 이름: `[스트리머명｜방송제목] yy-mm-dd hh：mm：ss.mp4` (윈도우 제한으로 `｜` `：`는 전각 문자). 제목은 최대 50자, 없으면 `[스트리머명]`.
- 동시 저장 파일은 시각이 모두 같습니다.

## 팝업과 설정 페이지

- **팝업**: 현재 채널의 움짤·영상 스위치와 저장 길이, 상태, 다듬어 저장·교차편집 버튼, 저장 위치 요약.
- **설정 페이지**(팝업의 ⚙ 설정 또는 아이콘 우클릭 → 옵션): 움짤·영상 화질, 압축 품질, 소리 싱크, 기본 저장 위치, 채널 목록, 단축키, 이용 안내.

## 채널별 켜기/끄기

- 스위치는 해당 채널에만 적용됩니다. 처음 보는 채널은 꺼진 상태로 시작합니다.
- 아이콘 배지: `움영` / `움` / `영` (수집 중), `OFF` (꺼짐), 없음 (채널 화면 아님).

## 저장 위치

| 방식 | 저장 위치 |
|---|---|
| 다운로드 (기본) | 다운로드/치지직움짤클립/스트리머명/방송제목｜날짜 |
| 선택한 폴더 | 선택한 폴더/스트리머명/방송제목｜날짜 (다운로드 폴더 밖 가능) |
| 매번 묻기 | 저장할 때마다 선택 |

- 방송 폴더: `방송제목｜yymmdd` (날짜는 방송 시작일, 제목이 없으면 날짜만). 교차편집 결과는 `교차편집` 폴더에 저장됩니다.
- 채널 전용 폴더: 설정 페이지 "채널"에서 지정하며, 고른 폴더/방송제목｜날짜에 저장됩니다.
- 사용자 폴더 자체(`C:\Users\이름`)와 윈도우·프로그램 폴더는 크롬이 막습니다. 그 안에 폴더를 만들어 고르십시오.
- 크롬을 다시 켜면 권한이 다시 필요할 수 있습니다. 권한이 없을 때는 다운로드/치지직움짤클립/스트리머명/방송제목｜날짜에 대신 저장됩니다.

## 영상 압축 품질

| 30fps 기준 | 480p | 720p | 1080p |
|---|---|---|---|
| 보통 | 1.8Mbps | 3.5Mbps | 6Mbps |
| **높음 (기본)** | 3Mbps | 6Mbps | 10Mbps |
| 최고 | 4.5Mbps | 9Mbps | 15Mbps |

- 크롬이 지원하면 **고정 화질 모드**(quantizer)를 사용합니다. 복잡한 장면에서도 화질이 유지되고, 그 구간만 파일이 커집니다. 팝업에 `높음 고정 화질(Q24)`처럼 표시됩니다. 지원하지 않으면 위 표의 비트레이트를 사용합니다.
- 고정 화질값(낮을수록 고화질): H.264 보통 28 / 높음 24 / 최고 20, VP9 40 / 34 / 28.
- 플레이어 화질이 잠깐 떨어져도 저장 크기와 버퍼는 유지됩니다. 저장 구간에 화질 저하가 있으면 알림에 표시됩니다. 플레이어 화질은 "자동" 대신 고정을 권장합니다.
- 높을수록 움직임이 많은 장면이 덜 뭉개집니다. 60fps는 × 1.4.
- 1Mbps ≈ 60초에 7.5MB. 파일 크기와 탭별 버퍼 메모리도 같은 비율로 커집니다.
- 키프레임이 2초 간격이라 단축키 저장의 실제 길이는 최대 2초 길 수 있습니다.

## 움짤 크기

- 320 / 480 / 640 / 720 / 850 / 1280(720p급) / 1920px(1080p급). 720px는 세로 약 405줄, 850px는 약 478줄입니다.
- 원본을 줄일 때 고품질 축소를 사용합니다.
- 움짤은 장면마다 CPU로 압축하므로 1280px부터는 부하가 심할 수 있습니다. 장면이 빠지면 팝업에 경고가 표시됩니다.
- 단축키로 저장한 움짤이 20MB를 넘으면 선택 창이 뜹니다: **20MB로 줄이기**(화질 설정은 그대로, 가로세로만 줄임) / **그대로 저장**. 30초 동안 고르지 않으면 그대로 저장합니다.

## 녹화

1. 녹화 단축키(`chrome://extensions/shortcuts`에서 지정) 또는 팝업의 **● 녹화**
2. 누른 시점 10초 전부터 녹화됩니다. 아이콘 배지가 `REC`로 바뀝니다.
3. 같은 단축키(또는 팝업의 ■ 버튼)로 종료하면 바로 다듬기 화면이 열립니다. 처음 범위는 녹화 전체입니다.
- 최대 10분 또는 메모리 768MB에서 자동 종료됩니다.
- 녹화 중 영상을 멈추거나 다른 위치로 이동하면 그 지점에서 자동 종료됩니다.
- 영상이 켜진 채널에서만 사용할 수 있습니다.

## 다듬어 저장

1. 팝업의 **다듬어 저장** (또는 직접 지정한 단축키)
2. 최근 장면(영상 60초 / 움짤 15초)이 열립니다. 처음 범위는 저장 길이와 같습니다.
3. 초록 표시를 끌거나 `I` / `O` 키로 시작·끝 지정, `Space` 재생, `Ctrl+Z` 되돌리기
4. **저장하기** → MP4 또는 움짤 선택 → 그 채널 저장 위치에 저장 (저장 창에 예상 용량 표시)

## 화면 자르기 (다듬어 저장 · 교차편집)

- 비율: 자르지 않음 / 자유 / 16:9 / 9:16 / 1:1 / 4:3
- 틀 안쪽을 끌어 이동, 모서리로 크기 조절. 틀 안쪽만 저장됩니다.
- 많이 자를수록 흐려집니다. 많이 자를 경우 영상 화질 1080p를 권장합니다.

## 교차편집

- 영상이 켜진 채널은 영상 버퍼(60초, 소리 포함), 움짤만 켜진 채널은 움짤 버퍼(15초, 소리 없음)를 가져옵니다.
- 큰 화면은 편집 결과, 오른쪽은 방송별 화면과 싱크 조절, 아래는 타임라인입니다.

| 조작 | 기능 |
|---|---|
| `Space` | 재생 / 멈춤 |
| `1`~`5` / 화면 클릭 | 그 순간부터 해당 방송으로 전환 |
| `Shift`+`1`~`5` | 선택 구간 전체 변경 |
| 경계선 끌기 | 컷 이동 |
| `Delete` | 선택 구간 앞의 컷 삭제 |
| `I` / `O` | 내보낼 범위 시작 / 끝 |
| `←` `→` (`Shift`) | 0.1초 (1초) 이동 · `,` `.` 한 프레임 |
| `Ctrl`+`Z` | 되돌리기 |

- **소리로 자동 맞추기**: 같은 목소리가 섞인 합방에서 잘 맞습니다. 움짤 버퍼 트랙은 수동으로 맞춥니다.
- 내보내기: MP4(화질·fps·압축 품질) 또는 움짤(최대 15초). 기본 저장 위치/교차편집 폴더에 저장됩니다.
- 편집 탭을 닫으면 가져온 장면도 사라집니다.

## 동시 저장 (Alt+Shift+D)

- 영상이 켜진 모든 탭이 같은 순간에 각자 저장합니다.
- 방송마다 송출 지연이 달라 화면 속 순간은 몇 초씩 어긋날 수 있습니다.
- 가려진 탭은 크롬이 영상 처리를 줄이므로 방송별로 창을 따로 띄우는 것을 권장합니다.

## 영상 동작 방식

1. `captureStream()`으로 영상·소리를 복사합니다 (재생 영향 없음).
2. H.264(불가 시 VP9) / AAC(불가 시 Opus)로 계속 압축해 최근 60초를 보관합니다.
3. 일시정지 중에는 담지 않으며, 재생 재개나 1.5초 넘는 이동 시 새로 담습니다.
4. 색은 BT.709·TV 범위로 직접 변환합니다. 압축기 검사 결과에 따라 보정 방식으로 자동 전환합니다.

## 설치 / 업데이트

1. 압축을 풀어 `chzzk-webp-clip` 폴더를 둡니다. 설치 후 폴더를 지우거나 옮기면 안 됩니다.
2. `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다** → 폴더 선택
3. 업데이트 시: 파일을 덮어쓴 뒤 확장의 새로고침(↻)
4. 열려 있던 치지직 탭 새로고침
5. `chrome://extensions/shortcuts`에서 단축키 확인

## 메모리 사용량 (탭당)

| 항목 | 설정 | 버퍼 |
|---|---|---|
| 영상 60초 (높음) | 480p / 720p / 1080p | 약 22 / 45 / 75MB |
| 움짤 15초 | 480px 12fps (기본) | 약 3~6MB |
| | 1280px / 1920px 12fps | 약 10~25 / 20~45MB |

- 교차편집 탭은 트랙마다 버퍼의 약 2배를 추가로 사용하며, 닫으면 반환됩니다.
- 4~5개 탭을 켤 때는 480p를 권장합니다.

## 보안·개인정보

- 권한: `storage`, `downloads`, `offscreen`만 사용. 페이지 접근은 `chzzk.naver.com`으로 한정.
- 외부 코드 없음 (CSP로 외부 스크립트 차단).
- 외부 전송은 스트리머 이름·방송 제목 조회(`api.chzzk.naver.com`, 채널 ID·영상 번호만)뿐입니다.
- 만든 파일에 개인정보가 들어가지 않습니다.
- 보호된 영상(SecurityError, DRM)은 우회하지 않습니다.
- 공유·업로드 기능은 없습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 아이콘에 빨간 `!` | 치지직 탭이 아니거나 설치 전부터 열린 탭 → 새로고침 |
| "이 채널은 ○○이 꺼져 있습니다" | 팝업에서 해당 채널 스위치 켜기 |
| 단축키 무반응 | `chrome://extensions/shortcuts`에서 확인 |
| "영상을 찾지 못했습니다" | 치지직 화면 구조 변경 → `content/selectors.js` 수정 |
| "(소리 없음)" | 소리 압축이 실패하면 다른 방식(Opus)으로 자동 재시도합니다. 계속되면 크롬 업데이트 |
| 가끔 화질이 크게 떨어짐 | 플레이어 화질을 1080p로 고정 (알림에 "플레이어 화질이 ○p로 떨어져" 표시 여부 확인) |
| 방송 화면 버벅임 | 켠 채널 수 줄이기, 화질 낮추기 |
| 움직임이 많은 장면이 뭉개짐 | 압축 품질을 "최고"로 |
| 색이 진하거나 하얗게 뜸 | 팝업에 색 변환 경고가 있으면 크롬 그래픽 가속 켜기 |
| 소리가 빠름/느림 | 설정의 소리 싱크 보정 (빠르면 +, 느리면 −) |
| 폴더가 `chzzk-clips`로 생김 | 시스템이 한글 이름을 거부해 영문으로 대체 저장 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 정보, 권한, 단축키 |
| `background.js` | 단축키, 배지, 다운로드 |
| `content/content.js` | 영상 찾기, 채널 확인, 움짤 수집·저장, 알림 |
| `content/video-clip.js` | 영상·소리 압축·저장, 교차편집 스냅샷 |
| `content/mp4-mux.js` / `webp-mux.js` | MP4 / 애니메이션 WebP 조립 |
| `content/selectors.js` | 치지직 화면 선택자, API 주소 |
| `editor/*` | 교차편집·다듬어 저장 화면, 내보내기 |
| `popup/*` | 팝업 |
| `settings/*` | 설정 페이지, 폴더 선택, 이용 안내 |
| `offscreen/*` | 파일 조립용 보이지 않는 페이지 |
| `shared/*` | 기본값, 채널 설정, 폴더 보관, 색 변환 |
